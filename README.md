# GridCast

Day-ahead Italian electricity load forecasting, built on a complete Cloud/DevOps platform featuring Kubernetes, GitOps with Argo CD, Terraform, Ansible, and observability.

Data: [Energy-Charts](https://energy-charts.info) (Fraunhofer ISE, CC BY 4.0) and [Open-Meteo](https://open-meteo.com).
