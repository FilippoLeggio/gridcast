# GridCast

Previsione del carico elettrico italiano del giorno dopo, con una piattaforma Cloud/DevOps completa: Kubernetes, GitOps con Argo CD, Terraform, Ansible e osservabilità.

Dati: [Energy-Charts](https://energy-charts.info) (Fraunhofer ISE, CC BY 4.0) e [Open-Meteo](https://open-meteo.com).
